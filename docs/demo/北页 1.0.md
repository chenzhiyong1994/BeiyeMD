# 把每一页，写成自己的节奏

北页是一款本地优先的多文档 Markdown 编辑器。预览排版、检查源码、整理文档，都在同一个安静的工作区里完成。

> 文件留在你的电脑，写作保持自己的节奏。

## v1.0 写作清单

* [x] 在一个窗口管理多份文档

* [x] 预览与完整 Markdown 源码随时切换

* [x] 检查格式、表格、图片与标题层级

* [ ] 写下下一篇真正重要的内容

| 工作流  | 北页如何处理       | 结果       |
| ---- | ------------ | -------- |
| 多文档  | 批量打开、筛选与快速切换 | 少开窗口，更专注 |
| 排版检查 | 预览模式隐藏语法符号   | 看清结构与节奏  |
| 源码排错 | 固定行号与查找高亮    | 快速定位格式问题 |

## 从这一页开始

不用导入，不用登录。打开一个普通 Markdown 文件，就可以开始。
