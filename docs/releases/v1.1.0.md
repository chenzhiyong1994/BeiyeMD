# BeiyeMD 1.1.0 · Windows 与 macOS / Windows and macOS

北页现在为 Windows 以及 Apple 芯片、Intel 芯片 Mac 提供独立安装包。这个版本没有改变“一个更轻快的 Markdown 打开方式”：文件仍只保存在本地，多文档、预览与源码、Markdown 检查、图片与表格工具都保持一致。

BeiyeMD now ships separate downloads for Windows, Apple silicon Macs, and Intel Macs. The local-first multi-document workspace and editing experience remain the same across platforms.

## 下载 / Downloads

| 平台 | 文件 |
| --- | --- |
| Windows x64 | `BeiyeMD-Setup-1.1.0-Windows-x64.exe` |
| macOS Apple 芯片 / Apple silicon arm64 | `BeiyeMD-1.1.0-mac-arm64.dmg` |
| macOS Intel x64 | `BeiyeMD-1.1.0-mac-x64.dmg` |
| 全部文件校验值 / Checksums | `SHA256SUMS.txt` |

## macOS 适配

- Finder 打开的多份 Markdown 文件会进入同一个工作区，而不是各自产生零散窗口。
- 快捷操作在 Mac 上显示并响应 `Command` 组合键。
- 左上角布局为红黄绿窗口按钮留出空间，并保留可拖动的标题区域。
- macOS 文件路径保留大小写语义；保存、改名、图片资源、PDF 导出和外部文件刷新沿用同一套本地文件模型。
- Apple 芯片与 Intel 版本分别在匹配架构的 GitHub macOS 环境中构建，并检查应用架构、文件关联、随附许可证、代码签名结构和 DMG 挂载。

## 安全提示 / Safety notice

macOS 版本使用无需开发者账号的临时签名，**未经 Apple 公证**。首次打开时系统可能阻止运行。只有在确认文件来自本项目官方 GitHub 且 `SHA256SUMS.txt` 校验一致后，才按 [macOS 安装说明](https://github.com/chenzhiyong1994/BeiyeMD/blob/v1.1.0/docs/macos-installation.md) 使用“系统设置→隐私与安全性→仍要打开”。

The macOS build uses an ad-hoc signature and is **not notarized by Apple**. macOS may block its first launch. Only use **System Settings → Privacy & Security → Open Anyway** after confirming that the DMG came from this official repository and matches `SHA256SUMS.txt`.

Windows 社区构建同样未购买商业代码签名，SmartScreen 可能要求确认。发布文件不包含账号、云同步或后台上传能力。
