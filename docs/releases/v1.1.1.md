# BeiyeMD 1.1.1 · 编辑体验优化 / Editing refinements

这个补丁版本集中改善日常打开、阅读和编辑 Markdown 的体验，并为 Windows 增加更顺手的新建入口。

This patch focuses on smoother everyday Markdown opening, reading, and editing, and adds a faster creation entry point on Windows.

## 改进 / Improvements

- 首次打开文件时，不再因为编辑器规范化换行而错误显示“未保存”，未修改关闭也不会出现保存提醒。
- 预览与源码视图切换时保留光标和滚动进度，避免跳到文末。
- 源码视图增加清晰可见的纵向滚动条。
- Windows 安装后，可从资源管理器右键 **新建 > BeiyeMD Markdown Document** 直接创建 `.md` 文件；卸载时会清理对应注册项。

- Freshly opened files are no longer marked unsaved because of editor line-ending normalization, so closing an untouched file does not show a save prompt.
- Preview and Source preserve cursor and scroll progress when switching instead of jumping to the end.
- Source view now has a clearly visible vertical scrollbar.
- After installation on Windows, create `.md` files from Explorer via **New > BeiyeMD Markdown Document**; uninstalling removes the registration.
