# BeiyeMD 1.1.2 · 源码保真与紧凑阅读 / Source fidelity and denser reading

这个补丁版本修复预览与源码切换时 Markdown 原文被编辑器规范化覆盖的问题，并改善笔记本屏幕上的阅读密度。

This patch prevents editor normalization from overwriting the original Markdown when switching between Preview and Source, and improves reading density on laptop screens.

## 改进 / Improvements

- 首次切换到源码时保留磁盘中的原始 Markdown，列表项之间已经删除的空行不会在切换视图后自动恢复。
- 源码视图采用更紧凑的行距，减少类似“隔行空行”的视觉错觉。
- 预览视图收紧正文、列表、标题、引用和代码块的纵向间距，在笔记本一屏内展示更多内容。
- Markdown 空行仍遵循标准语义：普通段落之间的多个空行不会逐个映射为预览中的额外空白；需要显式换行时可使用行尾双空格或 `<br>`。

- The first switch to Source preserves the original Markdown from disk, and deleted blank lines between list items no longer return after changing views.
- Source uses tighter line spacing to remove the visual impression of a blank row between every line.
- Preview tightens the vertical spacing of text, lists, headings, block quotes, and code blocks so more content fits on a laptop screen.
- Markdown blank lines still follow standard semantics: repeated blank lines between ordinary paragraphs do not map one-for-one to extra Preview spacing; use two trailing spaces or `<br>` for an explicit line break.
