# BeiyeMD 1.1.3 · 查找结果自动定位 / Find result navigation

这个补丁版本让查找替换直接定位到当前结果，解决长文档中只有高亮、仍需手动寻找的问题。

This patch makes Find and Replace scroll directly to the active result, so matches in long documents are easy to locate.

## 改进 / Improvements

- 预览与源码模式切换匹配时，自动滚动到对应位置；上下切换与首尾循环均可使用。
- 保留查找面板的输入焦点，支持连续按 Enter / Shift+Enter 导航。
- 源码定位适配长行自动换行、窗口缩放与文末零宽正则匹配；高亮层同步文本宽度及制表符排版。
- 填写替换文本时保留当前匹配，避免高亮跳回首个结果。

- Preview and Source scroll to the active match when navigating forwards, backwards, or wrapping between the first and last results.
- Focus stays in the search panel for repeated Enter / Shift+Enter navigation.
- Source navigation handles soft-wrapped lines, window resizing, and zero-width regular expression matches at the end of a document. Highlights follow the text width and tab layout.
- Typing replacement text preserves the current match instead of resetting to the first result.
