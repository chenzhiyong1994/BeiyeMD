# BeiyeMD 1.1.4 · 文档位置记忆 / Per-document reading positions

修复多文档共用滚动位置的问题：在文档 A 中滚动后切到 B，B 不再跟着跳到同一位置；返回 A 时会恢复上次的阅读进度。

Switching documents now restores each document's own reading position. Scrolling document A no longer moves document B, and returning to A resumes where you left off.

## 改进 / Improvements

- 预览与源码模式均独立记住各文档的光标和阅读进度，首次查看从顶部开始。
- 快速切换编辑模式、新建或关闭文档时，位置恢复保持正确；源码行号同步滚动。
- 切换文档继续保留未保存草稿；位置记忆仅保留在当前窗口内，关闭文档后清除。
- 新增真实 Electron 界面的多文档位置回归检查，覆盖两种模式和相关新建、关闭操作。

- Preview and Source remember each open document's cursor and reading progress, with first visits starting at the top.
- Rapid mode changes and creating or closing documents preserve the correct position; source line numbers stay aligned.
- Unsaved drafts survive document switches. Positions are kept within the current window and cleared when a document closes.
- Added Electron UI regression coverage for document positions in both modes and the related new/close workflows.
