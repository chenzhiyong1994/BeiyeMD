# BeiyeMD v1.0.0 · 北页正式版

一个更轻快的 Markdown 打开方式。

北页是一款快速启动、专注轻巧的本地 Markdown 阅读与编辑器。1.0.0 将多文档工作区、预览与源码双模式、Markdown 质量检查、表格列宽和图片尺寸调整整合为一套稳定的桌面体验。

## 这一版值得体验

- 同一窗口批量打开、筛选、切换和跨文档搜索 Markdown 文件。
- 预览模式专注排版，源码模式提供完整 Markdown、固定行号和查找高亮。
- Markdown 检查覆盖标题层级、重复标题、代码围栏、表格、尾随空格和本地图片。
- 表格列宽可拖拽并持久化；图片保留原始尺寸，支持缩放与左中右对齐。
- 五套协同主题，以及简体中文、English、繁體中文完整界面。
- 文件始终留在本地，无需账号、导入或私有文档库。

## 下载与校验

下载 Windows x64 安装包 `BeiyeMD.Setup.1.0.0.exe`。本次社区构建尚未进行代码签名，首次运行时 Windows SmartScreen 可能要求手动确认。

安装包的 SHA-256 校验值见本 Release 附件 `SHA256SUMS.txt`。

```text
6FF2ED80B7C16B87F4B17869540487A1E85A3E99F754A4D2C9A1B208D7172546  BeiyeMD.Setup.1.0.0.exe
```

## 开始使用

打开一份或多份 `.md` / `.markdown` 文件即可开始。建议先试试 `Ctrl+P` 快速打开、`Ctrl+F` 查找替换，以及右上角的预览 / 源码切换。
