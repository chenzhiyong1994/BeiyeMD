# 最近更新

## v1.1.1 · 编辑体验优化

- 首次打开 Markdown 文档时，不再因为编辑器规范化换行而误报“未保存”。
- 在预览与源码之间切换时保留光标和阅读进度，不再自动跳到文章底部。
- 源码视图现在提供清晰、持续可见的纵向滚动条。
- Windows 安装后，可从资源管理器右键“新建”菜单直接创建 BeiyeMD Markdown 文档。

## v1.1.0 · Windows 与 macOS

北页现在同时支持 Windows 与 macOS，仍然专注于更轻快地查阅和编辑本地 Markdown 文件。Mac 版本分别适配 Apple 芯片与 Intel 芯片，不依赖账号或云端服务。

### 新增 macOS 支持

- 提供 Apple 芯片 arm64 与 Intel x64 两种 DMG 安装包。
- 支持从 Finder 打开 Markdown 文件，并把连续打开的文件放入同一个工作区。
- 快捷操作在 Mac 上使用 Command 组合键，界面也为左上角窗口按钮留出了合适空间。
- 保存、改名、图片、PDF 导出与外部文件实时刷新保持跨平台一致。

### 多文档工作区

- 同一窗口可新建、批量打开、切换和筛选多份 Markdown 文档。
- 切换文档时保留未保存草稿；只剩一份文档时不显示多余的关闭按钮。
- 侧栏支持拖拽改宽、窄栏标签和悬停出现的边缘收起按钮。
- 文档标题可直接改名，标题区同步显示保存状态与字数。

### 写作与检查

- 「预览」用于排版写作，「Markdown」用于核对完整源码和固定行号。
- 全新的查找替换支持命中高亮、当前结果定位、大小写、全词和正则表达式，可在两种编辑模式中使用。
- 公式对话框支持简体中文、English 与繁體中文，并能插入行内或独立公式。
- Markdown 检查覆盖标题层级、重复标题、代码围栏、表格列数、行尾空格和丢失的本地图片。
- 表格支持拖拽列宽；图片支持保留粘贴尺寸、拖拽缩放和三种对齐方式。

### 视觉系统

- 工作区采用更宽的正文画布、轻量文档库与统一线性图标。
- 提供纯白浅色、纯黑深色、雾蓝、灰绿和深灰五套独立主题。
- 黑白主色图标已适配应用窗口、安装包和小尺寸显示。

## 建议体验

1. 一次选择多份 Markdown 文件，体验当前窗口内的文档切换。
2. 拖动侧栏边缘与表格列边界，观察宽度持久化。
3. 按 `Ctrl+F`（Mac 为 `Command+F`）使用查找替换，再切换到 Markdown 模式核对行号。
4. 从「编辑 → 插入公式」尝试行内和独立公式。
5. 从「主题」菜单比较五套配色。
