# 最近更新

## v1.0.0 · 把每一頁，寫成自己的節奏

北頁 1.0 是第一個適合日常使用的穩定版本。應用程式只讀寫你所選擇的本機檔案，不需要帳號或雲端服務；多文件管理、排版預覽、原始碼除錯與格式檢查已形成完整工作流程。

### 多文件工作區

- 在同一個視窗中新增、批次開啟、切換及篩選多份 Markdown 文件。
- 切換文件時保留未儲存草稿；只剩一份文件時，不顯示多餘的關閉按鈕。
- 側邊欄支援拖曳調整寬度、窄欄標籤，以及滑鼠停留時顯示的邊緣收合按鈕。
- 可直接從文件標題重新命名，標題區同時顯示儲存狀態與字數。

### 寫作與檢查

- 「預覽」用於排版寫作，「原始碼」用於核對完整 Markdown 與固定行號。
- 全新的尋找與取代支援命中醒目提示、目前結果定位、大小寫、完整單字與正規表示式，並可在兩種編輯模式中使用。
- 公式對話框支援簡體中文、English 與繁體中文，可插入行內或獨立公式。
- Markdown 檢查涵蓋標題層級、重複標題、程式碼圍欄、表格欄數、行尾空白與遺失的本機圖片。
- 表格支援拖曳欄寬；貼上的圖片會保留尺寸，並可拖曳縮放及設定靠左、置中或靠右。

### 視覺系統

- 工作區採用更寬的正文畫布、輕量文件庫與一致的線性圖示。
- 提供純白淺色、純黑深色、霧藍、灰綠與深灰五套獨立主題。
- 黑白主色圖示已針對應用程式視窗、安裝程式與小尺寸顯示完成調校。

## 建議先試

1. 一次選取多份 Markdown 檔案，體驗同一視窗中的文件切換。
2. 拖曳側邊欄邊緣與表格欄界線，觀察寬度持久化。
3. 按 `Ctrl+F` 使用新的尋找與取代，再切換到原始碼模式核對行號。
4. 從「編輯 → 插入公式」嘗試行內與獨立公式。
5. 從「主題」選單比較五套配色。
