# 最近更新

## v1.1.1 · 編輯體驗改善

- 首次開啟 Markdown 文件時，不再因編輯器正規化換行而誤報「未儲存」。
- 在預覽與原始碼之間切換時保留游標與閱讀進度，不再自動跳到文章底部。
- 原始碼檢視現在提供清楚、持續可見的垂直捲軸。
- 在 Windows 安裝後，可從檔案總管右鍵「新增」選單直接建立 BeiyeMD Markdown 文件。

## v1.1.0 · Windows 與 macOS

北頁現在同時支援 Windows 與 macOS，繼續專注於更輕快地查閱與編輯本機 Markdown 檔案。Mac 版本分別適用於 Apple 晶片與 Intel 處理器，不需要帳號或雲端服務。

### 新增 macOS 支援

- 提供 Apple 晶片 arm64 與 Intel x64 兩種 DMG 安裝檔。
- 支援從 Finder 開啟 Markdown 檔案，並將連續開啟的檔案放入同一個工作區。
- Mac 快捷操作使用 Command 組合鍵，介面也為左上角視窗按鈕保留適當空間。
- 儲存、重新命名、圖片、PDF 匯出與外部檔案即時更新在不同平台保持一致。

### 多文件工作區

- 在同一個視窗中新增、批次開啟、切換及篩選多份 Markdown 文件。
- 切換文件時保留未儲存草稿；只剩一份文件時，不顯示多餘的關閉按鈕。
- 側邊欄支援拖曳調整寬度、窄欄標籤，以及滑鼠停留時顯示的邊緣收合按鈕。
- 可直接從文件標題重新命名，標題區同時顯示儲存狀態與字數。

### 寫作與檢查

- 「預覽」用於排版寫作，「原始碼」用於核對完整 Markdown 與固定行號。
- 全新的尋找與取代支援命中醒目提示、目前結果定位、大小寫、完整單字與正規表示式，並可在兩種編輯模式中使用。
- 公式對話框支援簡體中文、English 與繁體中文，可插入行內或獨立公式。
- Markdown 檢查涵蓋標題層級、重複標題、程式碼圍欄、表格欄數、行尾空白與遺失的本機圖片。
- 表格支援拖曳欄寬；貼上的圖片會保留尺寸，並可拖曳縮放及設定靠左、置中或靠右。

### 視覺系統

- 工作區採用更寬的正文畫布、輕量文件庫與一致的線性圖示。
- 提供純白淺色、純黑深色、霧藍、灰綠與深灰五套獨立主題。
- 黑白主色圖示已針對應用程式視窗、安裝程式與小尺寸顯示完成調校。

## 建議先試

1. 一次選取多份 Markdown 檔案，體驗同一視窗中的文件切換。
2. 拖曳側邊欄邊緣與表格欄界線，觀察寬度持久化。
3. 按 `Ctrl+F`（Mac 為 `Command+F`）使用尋找與取代，再切換到原始碼模式核對行號。
4. 從「編輯 → 插入公式」嘗試行內與獨立公式。
5. 從「主題」選單比較五套配色。
